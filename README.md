# 🌐 Mini Projects using JavaScript

A collection of **8 beginner-to-intermediate frontend mini-projects** built using **HTML**, **CSS**, and **JavaScript**. Each project lives in its own folder and can be run independently in any modern browser.

---

## 📌 Repository Overview

This repository showcases a variety of practical JavaScript projects covering UI interactions, game logic, real-time utilities, and DOM manipulation — all built with a pure frontend stack (no frameworks or libraries required).

**Tech Stack:** HTML5 · CSS3 · JavaScript (ES6+)

## 🚀 Getting Started

No installation or build tools needed — each project runs directly in the browser.

1. **Clone the repository**
   ```bash
   git clone https://github.com/SamruddhiNadgouda/Min-Projects-using-Javascript.git
   ```

2. **Navigate into any project folder**
   ```bash
   cd "Min-Projects-using-Javascript/Calculator project"
   ```

3. **Open `index.html` in your browser**
   - Double-click the file, or
   - Right-click → Open with → Browser

## 📂 Project Details

### 1. 🧮 Calculator
A clean, functional calculator supporting addition, subtraction, multiplication, division, percentage, decimal input, delete (DE), and all-clear (AC).

**Key Concepts:** DOM manipulation, event handling, arithmetic evaluation

---

### 2. 🎨 Color Generator
Generates a random HEX color code on each click and updates the page background to display it.

**Key Concepts:** Math.random(), hex color generation, DOM style manipulation

---

### 3. 💱 Currency Converter
Converts a user-entered amount from one currency to another using live or predefined exchange rates.

**Key Concepts:** Input handling, conversion logic, DOM updates

---

### 4. 🎲 Dice Game
A two-player dice rolling game where each player rolls a dice and the higher number wins the round.

**Key Concepts:** Math.random(), image switching, conditional logic

---

### 5. 🎮 Game Project JS
An interactive browser-based JavaScript game with game logic, scoring, and user interaction.

**Key Concepts:** Event listeners, game state management, dynamic UI updates

---

### 6. 🟦 Simon Game
A classic memory game where the player must repeat a growing sequence of colored button flashes. The game ends on a wrong input.

**Key Concepts:** setInterval/setTimeout, arrays, sequence comparison, CSS animations

---

### 7. 🌡️ Temperature Converter
Converts temperature values between Celsius, Fahrenheit, and Kelvin with instant results.

| From | To | Formula |
|------|----|---------|
| Celsius | Fahrenheit | `(C × 9/5) + 32` |
| Celsius | Kelvin | `C + 273.15` |
| Fahrenheit | Celsius | `(F − 32) × 5/9` |

**Key Concepts:** Input events, arithmetic formulas, DOM updates

---

### 8. ✅ ToDo App
A task management app where users can add new tasks, mark them as complete, and delete them from the list.

**Key Concepts:** Array manipulation, localStorage, dynamic list rendering, event delegation
